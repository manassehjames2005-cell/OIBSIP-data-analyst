# OIBSIP – Data Analytics Internship

## 📊 Oasis Infobyte Data Analytics Internship

This repository contains the projects completed as part of my **Data Analytics Internship at Oasis Infobyte**.

The projects focus on data cleaning, exploratory data analysis, customer behaviour analysis, data visualization, and extracting meaningful business insights using Python.

---

## 🚀 Tasks Completed

### 🔹 Task 1 – EDA on Retail Sales Data

**Objective:**
Perform Exploratory Data Analysis on retail sales data to identify sales trends, customer behaviour, product performance, and useful business insights.

**Work Performed:**

* Loaded and inspected the retail sales dataset
* Checked dataset shape, data types, and missing values
* Performed descriptive statistical analysis
* Analyzed monthly and quarterly sales trends
* Studied customer age groups and gender distribution
* Identified the top-selling products
* Analyzed revenue by product category
* Created a correlation heatmap
* Created additional visualizations to identify hidden patterns
* Added observations after visualizations
* Provided actionable business recommendations

**Technologies Used:**

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

### 🔹 Task 2 – Customer Segmentation Analysis

**Objective:**
Analyze customer purchasing behaviour and divide customers into meaningful groups based on their transaction patterns.

**Work Performed:**

* Loaded and explored the customer transaction dataset
* Cleaned and prepared the data
* Calculated customer-level purchase metrics
* Analyzed customer purchasing behaviour
* Applied RFM analysis where applicable
* Used data visualization to understand customer groups
* Applied clustering techniques for customer segmentation
* Compared different customer segments
* Derived business insights from customer behaviour
* Suggested strategies for targeted customer engagement

**Technologies Used:**

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

---

### 🔹 Task 3 – Data Cleaning and Preprocessing

**Objective:**
Clean and transform raw data into a structured and analysis-ready dataset.

**Work Performed:**

* Loaded and inspected the raw dataset
* Checked for missing values
* Identified duplicate records
* Handled missing and inconsistent data
* Corrected data types
* Standardized column values
* Detected and handled data quality issues
* Checked numerical and categorical columns
* Prepared the cleaned dataset for further analysis
* Compared the dataset before and after cleaning

**Technologies Used:**

* Python
* Pandas
* NumPy
* Jupyter Notebook
